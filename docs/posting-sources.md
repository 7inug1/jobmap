# 공고 링크 읽기 측정

플랫폼마다 실제 공고 링크 1개를 `/api/posting`으로 읽은 결과다. 측정일 2026-11-09, 로컬 개발 서버 기준. 배포한 Cloudflare Workers에서는 접속 IP가 달라 결과가 바뀔 수 있다.

"됨"은 지원 요건이 들어 있는 글을 읽었다는 뜻이다. "안 됨"은 사용자에게 본문을 붙여 넣으라고 안내한다.

| 플랫폼 | 결과 | 읽은 글자 수 | 메모 |
|:---|:---:|---:|:---|
| 당근 채용 | 됨 | 3,120 | 구조화 데이터. 공고만 깔끔하게 읽음 |
| 원티드 | 됨 | 1,354 | 구조화 데이터에 주요 업무만 있어 화면 영역을 읽음 |
| 점핏 | 됨 | 1,515 | 복지, 기업 정보가 섞임 |
| 쿠팡 채용 | 됨 | 9,410 | 회사 소개가 길게 섞임 |

| Ashby | 됨 | 6,515 | |

| 잡코리아 | 안 됨 | 0 | 상세 요강이 페이지 글에 없음 |

아직 재지 못한 곳: 네이버, 우아한형제들, 프로그래머스, Indeed, SmartRecruiters(측정할 공고 링크를 얻지 못함).

입력 화면의 목록은 `web/src/features/start/posting-sources.ts`에 있다. LinkedIn은 약관을 확인하기 전까지 화면에서 붙여넣기로 안내한다.
